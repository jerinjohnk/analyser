Commitscape

Poster-style visualizations of a Git repository's history. Runs entirely on this computer: nothing is uploaded.

1Repository ▶

Choose your project folder with Browse… or type its path.

2Date range ▶

Default: this year so far once it's past 1 July, otherwise all of last year. Pick a preset or set your own dates.

3Authors ▶

Merge people who committed under several names and choose the name shown in the designs. Select authors and press Merge, or edit a person's name directly. Unticked authors are left out.

Possible duplicates ▶
All authors ▶
Select authors to merge them.

4File groups ▶

How files are grouped in the designs' "share of lines changed". Path rules are checked first, top to bottom; every other file is grouped by language. Unticked groups are left out of every design (lines, bubbles, file counts), which is useful for lockfiles and generated code.

Path rules ▶

Comma-separated globs: *.test.* matches the file name anywhere, android/** a folder from the repository root, **/__tests__/** a folder at any depth, *.{ts,tsx} either extension.

Languages ▶
Select languages to merge them into one group.
